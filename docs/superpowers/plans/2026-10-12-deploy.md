# Deploy plan (PS3)

Spec: `docs/superpowers/specs/2026-10-12-deploy-design.md`. Each step ends with the full test suite passing. William approves every commit and push.

## Part A

1. **Repository hygiene.** `.gitignore` covers `node_modules/`, `dist/`, `data/`, `.env*`, `.vercel/`. First commit is the PS2 code as handed in, so the history starts from it.
2. **Store on Postgres.** Add `pg` (dependency) and `@electric-sql/pglite` (dev dependency). Write `server/pg.js` (the two adapters) and `server/migrations.js` (migration 1 plus `migrate()`). Make `server/db.js` async against the adapter. Make every route in `server/app.js` async. Convert `db.test.js` and `app.test.js` to in-memory PGlite. `restart.test.js` keeps proving data survives a restart, now through a PGlite directory.
3. **Time zone.** `localDay()` uses `America/Detroit` explicitly, with a test that 11 PM Detroit time on Oct 12 is still Oct 12 when the clock reads 03:00 UTC Oct 13.
4. **`/api/version`.** Returns `VERCEL_GIT_COMMIT_SHA`, or `"dev"` locally. Test both.
5. **Basic auth.** Middleware plus tests: no header is 401 with `WWW-Authenticate`, the wrong password is 401, the right one passes, `/api/version` is open, settings missing on Vercel refuses everything.
6. **Vercel wiring.** `api/index.js` (creates the pg store once per instance and exports the app), `vercel.json` (build command, `/api/(.*)` rewrite, SPA fallback), `scripts/migrate.js` with `npm run migrate`. Smoke-test locally with `vercel build`.
7. **README and `DEPLOY.md`** with the three fixed lines and the settings by name.
8. **William, by hand:** create the public GitHub repo `whuddd/trade-journal`; import it in Vercel; add Neon from the Storage tab (Production); add `BASIC_AUTH_USER` and `BASIC_AUTH_PASSWORD` in the dashboard.
9. **Push and check:** visible change shows live; add a trade, push, it is still there; `vercel logs` shows the request.

## Part B

10. **Migration 2:** users, sessions, `user_id` columns, `activity_days` re-keyed. Test that migrating a database with Part A rows keeps every row.
11. **Auth module** (`server/auth.js`): GitHub authorize redirect with state cookie, callback with code exchange (GitHub client injected so tests use a fake), user upsert, owner claims orphan rows, session cookie, `/api/me`, sign-out.
12. **Authorization:** replace basic auth with `requireUser` on every data route and `requireOwner` on rule writes. Scope every trade, stats, setups and activity query by user. Tests: signed out is 401; member writing a rule is 403; member reading another member's trade is 404; owner can write rules.
13. **Frontend:** sign-in screen, the signed-in user's login and avatar with Sign out in the header, the rule editor read-only for members.
14. **William, by hand:** register the GitHub OAuth App with both callback URLs; put `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET` and `OWNER_GITHUB_ID` into Vercel; remove the basic auth settings.
15. **Push and check:** `curl` the protected path gets 401; a second GitHub account gets 403 on `POST /api/rules`; the Part A trade is still there; `/api/version` matches `main`.
16. **`DEPLOY.md` levels table**, gitleaks over the full history, then the showcase pull request to `umsi212F2026/student-showcase` with `projectUrl` equal to `App:` and `githubUrl` equal to the public repo.
17. **Canvas:** submit `https://github.com/whuddd/trade-journal`.
